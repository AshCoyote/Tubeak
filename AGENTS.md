# Base44 development environment

Tubeak is a plain PHP application (no build step, no package manager): PHP 7.4 +
Apache with the `.htaccess` rewrites, MariaDB for storage.

## Running it

```bash
docker compose -f docker-compose.base44.yml up -d --build
```

Then open http://localhost:3000. Only the repository is served (bind mount), so
edits are live; PHP has no watcher, just reload the page.

- `web` — `php:7.4-apache` built from `docker/base44/php.Dockerfile` (adds
  `mysqli`, `gd`, `mod_rewrite`, `AllowOverride All`, 256M upload limits).
- `db` — `mariadb:10.11`, initialised once from `tubeak.sql` on an empty
  `db-data` volume. To re-import the dump, `docker compose -f
  docker-compose.base44.yml down -v` and start again.

Seeded login: `admin` / `12345678` (the installer's demo account).

## Things that are non-obvious

- `includes/info.php` is normally generated by `install/index.php`. Here it reads
  `TUBEAK_DB_HOST`, `TUBEAK_DB_USER`, `TUBEAK_DB_PASSWORD`, `TUBEAK_DB_NAME`
  and `TUBEAK_SITE_URL` from the environment, so no credentials are committed and
  the web installer must not be run (it would overwrite the file). `TUBEAK_SITE_URL`
  is the public preview origin — every generated asset/redirect URL uses it.
- The sandbox checkout directory is mode `700`, so the `web` startup command
  runs `chmod o+rx /var/www/html` and makes `uploads/` and `sitemaps/` writable
  before Apache drops to `www-data`. `uploads/` is gitignored and created at
  startup.
- The base image is Debian bullseye, which is archived: the Dockerfile points
  apt at `archive.debian.org` before installing the GD build dependencies.
- `error_reporting(0)` in `includes/specs.php` hides PHP warnings; if a page comes
  back blank, set it to `E_ALL` temporarily and read `docker compose logs web`.
- Not wired up: video conversion needs `ffmpeg` (`settings.binary_path`), live
  streaming needs nginx-rtmp (the app force-disables `live_broadcast` when the
  server is not nginx), and outbound mail needs SMTP settings. The rest of the
  site — browsing, search, accounts, comments, playlists, admin panel — works.

## Verifying

```bash
curl -s -o /dev/null -w '%{http_code}\n' http://localhost:3000/   # 200, <title>Tubeak</title>
docker compose -f docker-compose.base44.yml ps                     # both services healthy
docker compose -f docker-compose.base44.yml logs --tail 50 web
```
